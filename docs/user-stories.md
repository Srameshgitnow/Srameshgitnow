# User Stories

## Core User Stories

1. As a user, I want to upload a CSV file so that I can analyze its contents.
2. As a user, I want to view the file as a table so that I can inspect records easily.
3. As a user, I want to sort and filter columns so that I can focus on relevant data.
4. As a user, I want to see charts generated from the dataset so that I can understand trends.
5. As a user, I want to save a dashboard configuration so that I can revisit my analysis.
6. As a user, I want AI suggestions so that I can receive better chart and insight recommendations.
