# Tech Stack Recommendation

## Frontend
- React
- TypeScript
- Vite
- Tailwind CSS or Material UI
- Recharts
- TanStack Table
- Papa Parse

## Backend
- Node.js
- Express
- PostgreSQL or SQLite
- Redis (optional)

## AI
- OpenAI or Gemini API
- optional prompt engineering and summarized insights

## Why this stack
- React + TypeScript is ideal for a fast, maintainable dashboard UI.
- Node.js keeps the backend simple and easy to deploy.
- PostgreSQL gives stronger reporting and saved configuration support.
- Recharts provides a clean charting experience for an MVP.
